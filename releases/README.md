# Android 安装包

- `TravelPlanner-v1.3-debug.apk`：最新版，修复全页面与弹窗滚动、弹窗裁切和移动端显示，并将模板改为编辑后确认添加。
- `TravelPlanner-v1.2-debug.apk`：修复首页横向溢出，新增应用图标、可复用清单模板和公开攻略 PDF。
- `TravelPlanner-v1.1-debug.apk`：优化预约图标、首页跳转与动效。
- `TravelPlanner-v1.0-debug.apk`：首个可安装版本，保留用于回退。

在红米手机上安装时，如系统拦截，请在“设置 → 隐私保护 → 特殊权限 → 安装未知应用”中允许当前文件管理器安装 APK。
